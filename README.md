## Git Commands Covered

| Command | Purpose |
|---|---|
| `git log` | Displays commit history. |
| `git log --oneline` | Displays commits in a compact format. |
| `git log --graph` | Displays commit history as a graph. |
| `git branch` | Lists available branches. |
| `git checkout` | Switches between branches. |
| `git switch` | Provides another way to switch branches. |
